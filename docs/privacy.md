# プライバシー方針

拡張は対象ページ上の利用者データを端末内で処理します。解析、広告、利用者データの外部送信、外部コード取得は行いません。拡張設定は `chrome.storage.local` に、元ツールの既存データは対象originの保存領域に残ります。

新しいポケモンとイベントを早期反映するため、対象ページをブラウザセッションで最初に開いたときだけ、GitHubの `raw.githubusercontent.com/nitoyon/pokesleep-tool` から公開JSONデータを取得します。この通信にはランキング条件、ボックス、閲覧内容その他の利用者データを含めません。検証済みJSONと確認時刻は `chrome.storage.local` にキャッシュされ、セッション内の確認済み状態は `chrome.storage.session` に保持されます。これらは拡張を削除すると削除されます。取得するのはデータだけで、JavaScriptその他の実行コードは取得・実行しません。

今後権限やデータ取扱いを追加する場合は、実装前に目的、保持期間、共有先、削除方法を本文とストア表示へ反映します。必要最小限を超える権限は要求しません。
