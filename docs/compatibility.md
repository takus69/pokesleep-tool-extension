# 互換性と上流変更への対応

対応条件をURLだけで推定せず、必要なDOM契約、保存スキーマ、データ版を段階的に検査します。保存値を自動修復・上書きしません。データ更新全体が壊れている場合は検証済みのキャッシュまたは同梱データへ戻し、未知仕様が一部だけの場合は該当ポケモン・イベント・指標だけを除外します。

未対応イベントが選択されている場合もランキング画面自体は使用できますが、イベント効果を適用しないことを計算前と結果表示中に警告します。利用者にはページ再読み込み、拡張更新、解消しない場合の開発元への連絡を順に案内します。データ更新で対応できない新スキルや計算式は拡張本体を再リリースします。

上流更新時はforkの `scripts/upstream-boundary.json` と関連差分を確認し、adapter fixture、domain同値テスト、実ブラウザ疎通を更新します。対応範囲をリリースノートに記録し、緊急時は機能フラグで問題機能だけを既定無効にします。リモート設定やリモートコードには依存しません。リモートJSONは計算式を表現する命令として扱いません。
