# ストア公開・リリース手順

1. CHANGELOG、version、対応上流版、ライセンス通知を更新。
2. `npm ci` と `npm run verify` をクリーン環境で実行。
3. Chrome／Edgeの最新安定版で手動受入試験。
4. `dist/` のmanifestと内容を確認し、外部コードがないことを確認。
5. 再現可能なZIP、ストア説明、画像、プライバシー回答を作成。
6. Chrome Web Storeへ提出後、同一ソースからEdge Add-onsへ提出。
7. タグとGitHubリリースを作成し、審査結果と既知問題を記録。

署名鍵、ストア資格情報、公開操作は管理者が行います。安定版公開と移行確認が完了するまでfork公開ページは維持します。
