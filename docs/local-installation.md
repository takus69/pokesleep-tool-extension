# Chrome／Edgeへのローカルインストール

ストア公開前の開発・受入確認用手順です。配布元を確認できる `dist` だけを使用してください。

## 1. ビルド

リポジトリから確認する場合は、Node.js 20以上を用意して次を実行します。

```powershell
git submodule update --init --recursive
npm install
npm run verify
```

成功するとリポジトリ直下に `dist` が生成されます。

## 2. Chromeへ読み込む

1. `chrome://extensions` を開く。
2. 右上の「デベロッパー モード」を有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」を押す。
4. このリポジトリの `dist` フォルダーを選ぶ。

## 3. Edgeへ読み込む

1. `edge://extensions` を開く。
2. 左側の「開発者モード」を有効にする。
3. 「展開して読み込み」を押す。
4. このリポジトリの `dist` フォルダーを選ぶ。

## 4. 起動確認

1. [Pokémon Sleep Tool](https://nitoyon.github.io/pokesleep-tool/) を開く。
2. 元ツール上段の末尾に「ランキング」が表示されることを確認する。
3. ランキングを開き、条件を指定して1回計算する。
4. 元ツールのタブへ戻れることを確認する。

## 修正後の再読み込み

コードを修正した場合は `npm run build` を再実行し、拡張機能管理画面にある対象拡張の再読み込みボタンを押してから対象ページを再読み込みします。ページの再読み込みだけでは、更新されたcontent scriptが反映されない場合があります。

## 削除

拡張機能管理画面で「削除」を押します。拡張のChrome Storageに保存された設定とデータキャッシュも削除されます。元ツール自身のlocalStorageは拡張の削除対象ではありません。
