# 新ポケモン名の翻訳補完（#87）

## 1. 目的

自動取込したタマゲタケ・モロバレルを、選択した言語で表示する。利用者の修正依頼に基づき、今後の新ポケモンも同じ経路で補う。対象は5言語のポケモン名のみ。イベント・スキル・画面文言・アイコンの自動更新は対象外。

## 2. 入力仕様

公式上流の `src/i18n/{en,ja,ko,zh-CN,zh-TW}/pokemons.json` を非実行JSONとして取得する。`pokemons` の文字列辞書だけを受け付け、検証済みポケモン名に一致する項目に絞る。空文字、長すぎる文字列、制御文字、HTMLやi18nextの補間・参照構文は除外する。

## 3. 処理ロジック

取得・ブラウザ保存はChromium runtime、検証と適用はintegration、翻訳登録はランキングUI境界が担当する。同梱訳を優先し、取得訳は不足する名称だけ補う。英語名fallbackは英語辞書に登録し、他言語に英語を埋めて後日の翻訳を妨げない。元ツールの設定は読み取るだけとし、設定未保存時はブラウザ言語を初期値にする。

## 4. 出力仕様

選択候補・結果・詳細の既存翻訳関数に同じ名称辞書を提供する。翻訳は検証後に計算データとともにキャッシュへ保存し、再読み込み時にも利用する。旧キャッシュは翻訳なしで引き続き読み取れる。翻訳だけの変更も既存revisionで通知する。

## 5. 画面仕様・モック

レイアウトを変更しない。日本語設定では `Foongus → タマゲタケ`、`Amoonguss → モロバレル`。英語設定では原名のまま。既存の更新状態表示と計算中の適用待機を使う。上段タブの日本語固定表示は維持する。

## 6. 元ツールとのインターフェース仕様

固定submoduleを変更しない。取得したJSONは評価せず、名称辞書だけを型付きstatusから読み取る。既存のポケモン・イベント検証と未知仕様除外を維持する。元ツール所有のstorageは書き換えない。

## 7. Chrome拡張固有仕様

既存の固定2 URLに翻訳5 URLを追加し、同時取得をservice workerで共有する。既存host permission内で取得できるため権限を追加しない。全5言語を取得するため、言語切替後の再読み込みもキャッシュを利用できる。

## 8. 例外・エラー時の動作

翻訳の通信失敗・不正値は言語単位で既存の検証済み訳を保持する。計算JSONが正しければ計算データ更新を妨げない。利用可能な翻訳がなければ英語名fallbackを使用し、次のページ起動で再試行する。取得訳で同梱訳を上書きしない。

## 9. 検証・未決事項

新名称のネットワーク適用・キャッシュ再起動・失敗後の再試行・英語fallback後の日本語補完・同梱訳の維持・不正翻訳除外・旧キャッシュ互換性をテストする。全体検証とChrome/Edge unpacked受入を記録する。公開はPATCH版とレビュー済みリリースPR、両ストア提出で行う。
