## 3. ブラウザ非依存の処理

公式の `PokemonStrength`、`HelpCount`、食材定義、イベント効果定義を固定上流更新で取り込む。拡張独自のナッツ計算式は作らない。公式実装では食材おてつだいに追加食材が付随し、所持枠を消費する。いつでもタップ、所持上限、笛・回数指定で処理が異なるため、JSONの許可だけを先に緩めない。

現在の `src/integration/upstreamDataPack.ts` は `extraIng` と `carryLimitAdd: 10` を拒否する。対応イベントだけが除外される状態を、公式計算との一致を確認してから解除する。

実装箇所と確認事項:

- `src/integration/upstreamDataPack.ts`: `extraIng` の文字列検証、対応食材の検証、所持数加算10、`Halloween2`。未知の食材・効果・数値は引き続き除外する。
- `src/domain/UpstreamPokemonCalculation.ts`: 共通計算ポートから返す食材一覧に追加食材が含まれること。上流結果が4種類になるケースを確認する。
- ランキング: 食材指標、条件サマリー、食材フィルター、詳細プレビューの4食材表示・翻訳・アイコンを確認する。
- モンメン系統: 未確定の間は候補除外と理由を維持する。確定後は実データで検証し、既知仕様だけなら通常のJSON同期で受け入れる。新スキルなら別途公式計算への追従が必要。
