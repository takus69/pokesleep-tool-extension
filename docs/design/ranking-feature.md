# ランキング機能の外部仕様

基準実装は `C:\workspaces\pokesleep-tool` のfork版 `42b0c4ae` です。本書は画面と利用者から観察できる動作だけを定義し、内部アルゴリズムを仕様化しません。

## 目的

利用者は次の6目的を切り替えます。

1. 特定ポケモンのサブスキル・性格を比較
2. 特定ポケモンの食材構成を比較
3. 指定したきのみタイプの要員を検索
4. 指定食材を取得する要員を検索
5. 指定メインスキルの要員を検索
6. 選択マップに適するポケモンを検索

目的に応じて選択可能な評価指標が変わります。候補レベルは1〜100です。条件不足や範囲外の値では計算せず、修正対象を案内します。

## 計算と結果

- 計算は利用者がボタンを押した場合だけ開始する。
- 計算中は処理済み候補数を表示し、利用可能になれば途中順位を更新する。
- 利用者は計算を中止でき、中止済み計算が後から画面を上書きしない。
- 完了時は同じ評価値を順位グループとして表示する。
- 各候補にはポケモン、食材構成、性格、性能に影響するサブスキル、評価値を表示する。
- 計算不能な候補を推測値で順位へ含めない。

## 段階的な画面移行

最初のブラウザ確認版は6目的の主要対象、指標、レベル、進捗、中止、上位100順位グループを提供します。次段階でfork版の詳細条件、共有計算環境、条件保存、全順位ページング、手持ち個体比較、能力詳細を追加します。未移行機能がある間は画面に確認版であることを明示します。

## 元ツールとの関係

拡張は元ツールの上段タブ列へ「ランキング」を追加します。選択時は既存の計算・編集領域を一時的にランキング画面へ切り替え、RP・エナジー・評価タブを選ぶと元画面を復元します。元ツールの保存済み計算環境は読み取り専用で利用し、ランキング操作によって元ツールの保存値を変更しません。読み取れない場合は既定環境を利用するのではなく、公開品質段階までに互換性エラーとして停止する仕様へ強化します。
