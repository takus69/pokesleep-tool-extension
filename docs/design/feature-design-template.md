# 機能設計テンプレート

過剰に実装詳細を固定せず、実装前の認識合わせと、元ツールとの境界を明確にするために使用します。細かな見た目は文章だけで定義せず、画面モックを正とします。決定する必要がない事項は推測せず「未決事項」に残します。

## 1. 目的

- 解決する利用者の課題
- 対象範囲と対象外
- 完了条件

## 2. 入力仕様

- 元ツールから取得する情報
- 使用するDOM、保存データ、イベント
- データ形式と前提条件
- 欠落、不正値、未知仕様の場合の扱い

## 3. 処理ロジック

- 入力の検証、変換、計算、判定
- UI・DOM操作から分離する処理
- 再利用する既存処理
- 計算を停止または局所除外する条件

## 4. 出力仕様

- 表示・出力する項目
- 並び順と状態
- 操作の結果
- 追加・変更するDOMと挿入位置

## 5. 画面仕様・モック

- 元画面上の表示位置
- 表示、非表示、切り替え操作
- 既存画面との関係
- 必須表示項目
- レスポンシブ、スクロール、空・読込中・エラー状態
- モックまたは参照画像へのリンク

## 6. 元ツールとのインターフェース仕様

- 読み取るDOMとデータ
- 拡張が追加・変更・一時的に非表示にするDOM
- 元ツール機能の利用方法
- クリック等のイベント連携
- DOM変更、再描画、画面遷移の検知
- 上流変更の影響範囲
- adapterが公開する最小インターフェース

## 7. Chrome拡張固有仕様

- manifest、content script、service worker
- 実行タイミングとSPA対応
- Chrome Storage等の状態保存
- permissionsとhost_permissions
- Chromium固有部分と再利用可能部分の境界

## 8. 例外・エラー時の動作

- 安全に停止する単位
- 利用者へ表示する内容
- 再読み込み、拡張更新、問題報告等の復旧手順
- ログへ残す情報と、保存・送信しない利用者情報

## 9. 未決事項

- 実装前に決定が必要な事項
- 実装中または検証後に決める事項
- 選択肢と判断条件
