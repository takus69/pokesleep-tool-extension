# 利用者向けマニュアル

## 対応環境

- Windows／macOS版 Google Chrome
- Windows／macOS版 Microsoft Edge
- 対象ページ: [Pokémon Sleep Tool](https://nitoyon.github.io/pokesleep-tool/)

インストール方法は [Chrome／Edgeへのローカルインストール](local-installation.md) を参照してください。ストア公開前は開発者モードでの確認用です。

## ランキングを開く

対象ページを開くと、元ツール上段の末尾に「ランキング」タブが追加されます。ランキングを選ぶと元ツールのヘッダーと上段タブを残したままランキング画面へ切り替わります。RP、エナジー、評価、チームなど元ツールのタブを選ぶと元画面へ戻ります。

ランキングタブが表示されない場合は、ページを再読み込みし、拡張が有効であることと対象URLを確認してください。

## 基本的な使い方

1. 必要に応じて元ツールのエナジー画面でマップ、イベント、フィールドボーナス等を設定する。
2. 「ランキング」タブを開く。
3. 「目的」を選ぶ。
4. ポケモン、食材、きのみ、スキルなど表示された必須条件を設定する。
5. 評価する「ランキング対象」とレベル、詳細条件を確認する。
6. 「ランキングを計算」を押す。

計算中は候補数と途中順位を表示します。計算を中止した場合は、計算ボタンから再実行できます。同じ値の候補は同順位グループとしてまとめられ、「同順位の全条件を見る」から内訳を確認できます。

## 6つの目的

| 目的 | 主な用途 |
|---|---|
| ポケモンのサブスキル・性格を比較する | 同じポケモンの育成条件を比較 |
| ポケモンの食材構成を比較する | 同じポケモンのAAA、AAB等を比較 |
| きのみ要員を探す | 指定したきのみタイプの候補を横断比較 |
| 食材要員を探す | 指定食材を取得する候補を横断比較 |
| スキル要員を探す | 指定メインスキルの候補を横断比較 |
| マップに合うポケモンを探す | 元ツールで選択中のマップに合う候補を比較 |

目的によって利用できる評価指標は異なります。画面に表示されない組み合わせは選択できません。

## 計算条件

ランキングは元ツールのエナジータブ等で設定した最新の計算条件を使用します。「共有計算環境」欄の「編集」を押すと、元ツール自身の設定画面へ移動します。変更後にランキングへ戻ると、ページを再読み込みせず最新条件を取得します。

ランキング固有のレベル、進化前を含めるか、スキルレベル等はランキング画面で指定します。計算開始時点の条件は結果に保存され、あとから元ツール側の条件を変更しても、表示中の結果要約は書き換わりません。

条件変更後は変更前の結果を残して「条件変更あり／再計算が必要」と表示します。計算は自動で始まらないため、新しい条件で確認する場合は再度「ランキングを計算」を押してください。

## マップを変更する

「マップに合うポケモンを探す」は、元ツールで現在選ばれているマップを使用します。「マップ 編集」を押し、元ツールの計算条件画面で変更してからランキングへ戻ってください。

## 手持ち個体と比較する

「手持ちの個体を比較する」は元ツールのボックスを参照します。比較したいカードを選び、「この個体を比較する」を押してください。相当順位や計算できない理由が結果に表示されます。

ランキングタブへ移動すると、個体編集画面は元ツールが保存した最新の作業中個体から始まります。ランキング内の選択・編集は元ツールの個体やボックスへ保存されません。「おてつだい頻度」詳細の変更も一時的な試算で、閉じて開き直すと共有条件の値に戻ります。別タブへ移動して戻ると、確定前の編集内容は元ツールの個体へ戻ります。確定済みの比較結果はページ内で保持され、再読み込みすると消えます。共有計算条件は元ツールの設定画面で変更し、ランキングへ戻ると変更を読み直します。

ランキング画面からボックスの追加、編集、複製、削除、import、exportはできません。元ツール側でボックスを変更してからランキングを開き直してください。計算済みの比較結果は、計算時点の個体条件を保持します。

## データ更新と未対応項目

対象ページをブラウザセッションで最初に開いたとき、公開されている最新のポケモン・イベントJSONを確認します。既知の仕組みだけで構成される新ポケモンは拡張本体の更新前でも候補へ反映できます。

未知のスキルや計算式を含む項目は、誤った値を出さず該当ランキングだけから除外します。未対応イベントではイベント効果を適用しない旨を警告します。

## 困ったとき

### ランキングタブがない

1. 対象ページのURLか確認する。
2. 拡張機能管理画面で拡張が有効か確認する。
3. 拡張を再読み込みしてから対象ページを再読み込みする。

### 条件変更が結果へ反映されない

「条件変更あり／再計算が必要」と表示されている場合は、もう一度計算ボタンを押してください。計算済み結果は比較のため意図的に残しています。

### 互換性エラーが表示される

ページを再読み込みし、次に拡張を最新版へ更新してください。それでも解消しない場合は元ツールの保存値を削除せず、ブラウザ名と版、拡張の版、対象URL、表示されたメッセージを添えてGitHub Issuesへ報告してください。

## データとプライバシー

ランキング計算とボックス参照は端末内で行います。詳しくは [プライバシー方針](privacy.md) を参照してください。
