# 利用者向けマニュアル

この拡張は、[個体値計算機 for ポケモンスリープ](https://nitoyon.github.io/pokesleep-tool/iv/index.ja.html)のページに「ランキング」タブを追加します。育成候補や手持ちの個体を、個体値計算機の計算条件で比べられます。非公式のβ版です。

デスクトップ版Chrome・Edgeで使えます。Windowsで動作確認済みで、macOSは未検証です。

## 使い始める

対象ページを開く・再読み込みするたびに、ポケモンとイベントの最新データを確認します。画面は保存済みデータ（なければ同梱データ）で先に表示します。確認中も計算できますが、更新前に計算した結果には更新後に再計算の案内が表示されます。計算中の更新は終了まで待機し、結果を自動で変更しません。通信に失敗しても既存データを使え、再読み込みで再試行できます。未対応のスキル・効果を含む項目は従来どおり警告して除外します。

利用するブラウザに合わせて[Chrome Web Store](https://chromewebstore.google.com/detail/mpipkmcenpcfekbpjlhepmflnbjhgpfh)または[Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/fajkddnhbedmajmmnljclpjnfjopanhl)からインストールしてください。開発用のビルドを試す場合は[ローカルインストール手順](local-installation.md)を参照してください。

1. [個体値計算機のページ](https://nitoyon.github.io/pokesleep-tool/iv/index.ja.html)を開きます。
2. 画面上部の「ランキング」タブを押します。SP、エナジー、個体評価、チームのタブへ戻ることもできます。
3. 必要に応じて、個体値計算機のエナジー画面でマップ、イベントなどの計算条件を設定します。

「ランキング」タブが見つからない場合は、下の[困ったとき](#困ったとき)を確認してください。

## ランキングを計算する

### 表示言語

ランキングは元ツールに保存された言語設定を優先します。対応言語は日本語、英語、韓国語、簡体字中国語、繁体字中国語です。元ツールで言語を変更した後はページを再読み込みしてください。

ポケモン名は同梱翻訳を優先し、新ポケモンの不足する訳を公式の翻訳JSONから自動補完します。取得済みの訳は保存し、通信に失敗した場合も利用します。訳を取得できない名称は英語名で表示し、次のページ起動・再読み込みで再試行します。イベント名・スキル名・画面文言・アイコンは引き続き拡張に同梱されており、自動更新しません。上段の「ランキング」タブは現在、日本語固定です。

公開版0.3.0には、新ポケモンの訳が自動取込されない問題と、言語設定が保存されていない場合にランキングが英語になる問題があります。0.3.1候補でポケモン名の自動補完とブラウザ言語の初期値を修正しています。明示的に保存された言語は引き続き優先します。候補版はストア公開前です。

1. ランキング画面で、比べたい「目的」を選びます。
2. 画面に表示されたポケモン・食材・きのみ・スキルなどの必須項目を選びます。目的によって必要な項目は異なります。
3. 「ランキング対象」、レベルなどの条件を確認します。
4. 「ランキングを計算」を押します。
5. 計算が終わったら、順位と各候補の内容を確認します。同じ順位の候補は「同順位の全条件を見る」から確認できます。

計算中は進み具合と途中の順位を表示します。途中で中止した場合は、計算ボタンを押してやり直せます。

### 目的の選び方

| 知りたいこと | 選ぶ目的 |
| --- | --- |
| 同じポケモンで、サブスキル・性格の違いを比べたい | ポケモンのサブスキル・性格を比較する |
| 同じポケモンで、食材の組み合わせを比べたい | ポケモンの食材構成を比較する |
| きのみ担当の候補を探したい | きのみ要員を探す |
| 欲しい食材を集める候補を探したい | 食材要員を探す |
| メインスキルで候補を探したい | スキル要員を探す |
| 選んだマップに合う候補を探したい | マップに合うポケモンを探す |

目的によって選べる評価方法は異なります。画面に表示されない組み合わせは選択できません。

## 計算条件を変える

ランキングは、個体値計算機のエナジー画面などで設定した計算条件を使います。ランキング画面の「共有計算環境」にある「編集」を押すと、個体値計算機の設定画面へ移動できます。変更後にランキングへ戻ると、新しい条件を読み取ります。

「マップに合うポケモンを探す」では、個体値計算機で選んでいるマップを使います。マップを変えたい場合は「マップ 編集」から設定画面へ移動してください。

条件を変えても、ランキングは自動で再計算しません。画面に「条件変更あり／再計算が必要」と出たら、前回の結果を確認したうえで「ランキングを計算」を押してください。結果の「結果の計算条件」には、前回の計算に使った条件が残ります。

## 手持ちの個体と比べる

1. 「手持ちの個体を比較する」を押します。
2. 個体値計算機のボックスに保存されたカードから、比べたい個体を選びます。
3. 「この個体を比較する」を押します。結果に相当順位が表示されます。計算できない場合は理由が表示されます。

ランキングからボックスの追加・編集・削除はできません。ボックスを変更する場合は、個体値計算機で変更してからランキングへ戻ってください。

ランキング画面で個体を編集しても、個体値計算機に保存された個体・ボックス・計算条件は書き換わりません。確定前の編集は、別の上段タブへ移動して戻ると、個体値計算機で保存された個体に戻ります。比較を確定した結果はページを開いている間だけ残り、再読み込みすると消えます。「おてつだい頻度」の詳細で変えた値も、その画面での試算だけに使われます。

## 新しいポケモンやイベント

新しいポケモンやイベントの公開データを確認し、対応できる内容はランキングに反映します。まだ対応できないスキルや計算方法がある場合は、誤った結果を避けるため、該当候補を除外したり、警告を表示したりします。

## 困ったとき

### 「ランキング」タブがない

1. [対象のページ](https://nitoyon.github.io/pokesleep-tool/iv/index.ja.html)を開いているか確認します。
2. ChromeまたはEdgeの拡張機能の管理画面で、この拡張が有効になっているか確認します。
3. 拡張を再読み込みし、対象のページも再読み込みします。

### 条件の変更が結果に反映されない

「条件変更あり／再計算が必要」と表示されていたら、「ランキングを計算」を押してください。前回の結果は、比較できるように残しています。

### 互換性エラーが出る

まずページを再読み込みし、それでも直らなければ拡張を最新版に更新してください。解消しない場合は保存済みのデータを削除せず、[問題報告](https://github.com/takus69/pokesleep-tool-extension/issues)から連絡してください。ブラウザ名と版、拡張の版、開いていたページのURL、表示されたメッセージがあると調査しやすくなります。ボックスの中身は送らないでください。

## データとプライバシー

ランキングの計算とボックスの参照は、利用者の端末内で行います。詳しくは[プライバシー方針](privacy.md)をご覧ください。
