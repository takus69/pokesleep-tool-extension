# 利用者向けマニュアル

現バージョンは開発者向け疎通版です。対応する元ツールのページで拡張が互換性を確認し、成功時のみ右下に接続状態を表示します。元ツールのデータは読み取り検査だけを行い、変更しません。

ブラウザ確認版では元ツール上段の「ランキング」タブを押すと、選択中のSP、エナジー図、既存の編集領域が隠れ、fork版と同じランキング画面へ切り替わります。目的、対象、指標、レベルや詳細条件を選択して計算してください。条件保存、ページング、手持ち個体比較、能力詳細もfork版と同じ画面から利用できます。RP・エナジー・評価タブを押すと元画面へ戻ります。

ランキング計算には、元ツールのエナジータブ等で設定した最新の計算環境を使用します。ランキングの計算環境欄では現在値と詳細を確認できます。「編集」を押すと元ツール自身のエナジー／パラメーター画面へ移動します。変更後にランキングへ戻ると、ページを再読み込みせず最新条件を取得します。計算済み結果に表示される条件要約は計算時点の内容を保持し、条件変更後は自動的に再計算します。

手持ち個体との比較では、元ツールのボックスを参照します。ランキング側では個体を選択できますが、ボックスへの追加・編集・削除はできません。ボックスを変更する場合は元ツール側で変更してからランキングを開き直してください。

互換性エラー時はランキング等を実行せず停止します。ページ更新と拡張更新後も解消しない場合、元ツールの保存値を削除せず、リリース時に案内する問題報告先へブラウザ・拡張版・対象URLを連絡してください。
